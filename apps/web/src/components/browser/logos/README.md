# Browser logos

Each browser's own icon, taken from the browser itself so it is exactly what
people see on their computers:

| File           | Source                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------- |
| `chrome.png`   | `/opt/google/chrome/product_logo_256.png` in Google's `google-chrome-stable` package                |
| `edge.png`     | `/opt/microsoft/msedge/product_logo_256.png` in Microsoft's `microsoft-edge-stable` package (amd64) |
| `chromium.png` | `/usr/share/icons/hicolor/256x256/apps/chromium.png` in Debian's `chromium` package                 |
| `firefox.svg`  | `chrome/browser/content/branding/about-logo.svg` in Debian's `firefox-esr` package (`omni.ja`)      |

Google Chrome and Chrome are trademarks of Google LLC; Microsoft Edge is a
trademark of Microsoft Corporation; Firefox is a trademark of the Mozilla
Foundation. Brawzer runs these browsers as their makers ship them, and uses
their logos only to say which browser a session is. The Chromium logo comes
from the Chromium project. Bee Browser's icon is Brawzer's own
(`../engine-logo.tsx`).
